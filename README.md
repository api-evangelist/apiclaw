APIClaw provides a unified API access to multiple large language models including Claude, GPT, Gemini, and DeepSeek. Users can obtain an OpenAI‑compatible key for a flat‑rate subscription starting at $19 per month, with no per‑token billing or usage caps. The platform offers a developer portal, comprehensive documentation, pricing plans, and a blog, targeting AI developers and businesses seeking cost‑effective multi‑model access.

**Areas:** Company · Artificial Intelligence · LLM · Software-as-a-Service · Platform

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for APIClaw: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
